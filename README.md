# omnigram-rs 🚀

> ⚡ **Вайбкод чистой воды (Vibecoded by AI Agent)**  
> Экспериментальный автономный порт классического клиента **Telegram Desktop (C++20/Qt)** на **чистый Rust**.  
> Создан и развивается полностью силами AI-агентов под управлением `agent-hub`.

---

## 🛠 О проекте
- **Цель:** Точная реконструкция архитектуры и семантики Telegram Desktop на Rust без тяжелого Qt-рантайма.
- **Статус:** Автономная кодогенерация и реализация модулей (28 крейтов в workspace).
- **CI/CD:** Сборка и прогон тестов выполняются на GitHub Actions раннерах.

## 📦 Архитектура Workspace
- `crates/tl_*` — бинарный TL reader, writer и кодогенератор схемы Telegram.
- `crates/crypto_*` — криптографический слой MTProto 2.0 (AES-IGE, KDF).
- `crates/mtproto_*` — сессии, транспорты, авторизационные ключи, обмен Диффи-Хеллмана, RSA.
- `crates/tdata_*` & `crates/storage_*` — парсер `tdata` и локальных настроек/ключей сессии.
- `crates/models_*` — модели пользователей, чатов, сообщений, автозагрузки медиа.
- `crates/styles_parser` — парсер оригинальных файлов палитр и геометрии `.style`.
- `crates/ui_*` — визуальные элементы: окно, баблы, инпут, аватары.
- `crates/core_launcher` — точка входа и лаунчер приложения.
- `crates/agent-hub` — оркестратор задач и агентных блокировок.

## 🧪 CI
Все тесты и сборки запускаются на GitHub Actions (`cargo test --workspace` & `cargo build --release`).
